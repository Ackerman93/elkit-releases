# eLkit — плагины Revit для ЭОМ и СС

Здесь только установщик и обновления. Сайт: https://elkit.web.app

**Скачать:** [eLkit-setup.exe](https://github.com/Ackerman93/elkit-releases/releases/latest/download/eLkit-setup.exe) — последняя версия.

Установка: закройте Revit → запустите `eLkit-setup.exe` → отметьте свои разделы (электрик / слаботочник) → «Установить».
Revit 2023, 2024, 2026. Права администратора не нужны. Дальше eLkit сам предложит обновиться при запуске Revit.
